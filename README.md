# 3D Circle Animation – CSS Project

A visually engaging front-end project showcasing a 3D animated circle effect built purely using HTML and CSS. This project demonstrates the power of CSS animations, transforms, and creative design techniques.

##  Live Demo

*[Link](https://addi5520.github.io/Circle/)*

## Features

* Smooth 3D circle animation
* Dynamic color transitions using `hue-rotate`
* Pure CSS animation (no JavaScript used)
* Responsive design using viewport units (`vmin`)
* Clean and minimal code structure

## Tech Stack

* HTML5
* CSS3 (Animations, Transforms, Flexbox)

## Project Structure

Circle-Animation/
│── index.html
│── style.css
│── README.md

## How It Works

* Multiple circles are created using HTML elements
* CSS variables (`--i`) control size and animation delay
* `transform` and `translateZ` create a 3D effect
* `@keyframes` animate vertical movement and color changes
* 
## How to Run Locally

1. Clone or download this repository
2. Open `index.html` in your browser
3. Enjoy the animation
